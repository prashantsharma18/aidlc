# Brief for OpenWiki

Write documentation that helps an engineer or a coding agent understand this repository.

- Describe purpose, areas, key flows and integrations. Cite the file for every claim.
- Never include values from configuration, environment files, secrets or test fixtures.
- Prefer what the code cannot say: why an area exists, what depends on it, what must stay true.
- Keep the managed block in AGENTS.md to at most 10 lines, containing only headings and links
  into openwiki/. Do not summarise the wiki there.
- Do not modify CLAUDE.md.
