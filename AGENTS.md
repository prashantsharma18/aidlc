# aidlc framework: agent guide

Tool-neutral framework implementing the guide "From Intent to Verified Change".
Python 3.12 CLI; policies, templates and context standards in core/; adapters render
them for one AI coding tool. Owner: framework owners (Prashant Sharma).

## Map
- Design and plans: read docs/design/ before changing structure; plans in docs/plans/.
- `cli/aidlc/` the CLI; one module per subcommand in `cli/aidlc/commands/`
- `core/policy/` policies (YAML), validated by `core/schemas/`
- `core/templates/` stage-artefact templates; `core/context/` context standards
- `tests/` unittest suites
- Harness sources: `core/hooks/`; never edit the generated hooks folder under `.aidlc` in an installed repository

## Commands
- One-command check, must pass before you report done: `make test`
- Run the CLI from this checkout: `bin/aidlc --help`

## Standards
- Python 3.12: standard library plus PyYAML and jsonschema only. Hooks: standard library only.
- Every policy and template declares the guide sections it implements (`guide:`);
  run `bin/aidlc trace` after adding or changing one.
- Generated files carry a "Generated by aidlc" header. Edit their sources, never the output.
- Fail closed: unreadable input, a missing file or an unknown value is an error.

## Boundaries
- Never overwrite a file a person wrote; refuse and explain.
- Never weaken a deny rule in `core/policy/permissions.yaml` without a design change.
- No new dependency without asking first.
- Never change an existing test assertion to make a test pass. Stop and report.
