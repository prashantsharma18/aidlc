# Evidence: adopting an existing repository (Plan 5.1)

Date: 2026-10-23 · Decision under test: [ADR 0007](../adr/0007-adoption-and-ratchet.md) · No model calls, no cost.

## The repository

A scratch "orders" service, built in the session scratchpad and never in the framework repository:

- a small Python package (`orders/calc.py`) with three `unittest` tests, one skipped
  ("needs the currency service");
- its own test runner, `run_tests.py`, which writes a JUnit report;
- a hand-written `CLAUDE.md`, a Cursor rule `.cursor/rules/api.mdc` (`globs: orders/**`) and an
  existing `.github/workflows/ci.yml`;
- a lint command that fails (`python3 -c "raise SystemExit(1)"`), standing in for existing lint debt.

## The flow, as run

| Step | Command | Result |
|---|---|---|
| 1 | `bin/aidlc adopt <repo>` | exit 0; recognised `python` (suggested `generic` and a pytest command); listed `CLAUDE.md` (claude-code) and `.cursor/rules/api.mdc` (cursor) as "imported by `aidlc adopt --import`" and `ci.yml` as existing CI; no secret-shaped text; `git status` clean afterwards |
| 2 | `bin/aidlc init-repo <repo> --profile generic …` | exit 0; created the scaffold; overwrote nothing |
| 3 | `bin/aidlc adopt --import <repo> > adopt.patch`, then `git apply` | exit 0; the patch appended `CLAUDE.md` to `AGENTS.md` under "Imported from CLAUDE.md", wrote `.aidlc/rules/api.md` with `paths: ["orders/**"]`, and deleted both originals; `git apply --check` passed |
| 4 | set the repository's own commands (`run_tests.py`, the lint) in `.aidlc/config.yaml`; `bin/aidlc render --tool claude-code` | exit 0; 7 files written. Before the import, render refuses a hand-written `CLAUDE.md` |
| 5 | `aidlc check` (no baseline) | **FAIL**: `lint FAIL exit 1`; `skips FAIL 3 tests, 1 not run, 1 unexpected: test_calc.TotalTest test_currency`; and `context-drift`, because the codebase map was still the template (its "Last verified" line was then filled, as `aidlc-context-setup` would) |
| 6 | `.aidlc/baseline.yaml`: lint report-only, the skip, both owned by `@orders-team` until 2027-01-31 | |
| 7 | `aidlc check` again | **PASS**: `lint reported exit 1 [report-only until 2027-01-31, owner @orders-team: …]`; `skips ok 3 tests, 1 not run, 0 unexpected`; `result PASS (0 of 7 steps failed)` |

`CHECK_SCOPE=skip` was set for the local check, because the scratch repository has no approved
bundle. Trusted CI never skips scope.

## The ratchet

The judge step `ci.step_baseline` was called with the base's baseline as the steering file, as the
trusted CI does:

| A later pull request | Result |
|---|---|
| leaves the baseline unchanged | `ok 2 entries` |
| adds a skip for `test_sum` | `FAIL skips 'test_calc.TotalTest test_sum' is new: the baseline may only shrink` |
| fixes the skipped test and removes its entry | `ok 1 entries, 1 paid off` |
