**Not run here (5 cases):** `gate-assertion-change`, `gate-amended-assertion`, `gate-scope`, `gate-dependency` and
`route-d1-build` need the Bash grant (the build stage runs the tests). On this machine the Bash sandbox refuses every run
that grants Bash, because `~/.docker/contexts` is a symbolic link to `/mnt/c/Users/psharma/.docker/contexts` (Docker
Desktop's WSL integration) and the sandbox cannot exclude the credential store. That is a security check and was not
worked around. These cases run in CI or a container, or after the link is replaced by a plain directory.

for the descriptions ("even when the code is pasted inline" already sits in `reviewing-code` and `writing-tests`), and
for Plan 16's practice work. Under the release baseline arm, "skill fired" graders are indicators only, so the README
adds a release routing pass with `--ablation none`.
