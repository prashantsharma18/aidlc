  Tasks 4, 5, 7, 8 and the final review. If wrong, only trailer wording changes, or a task is re-reviewed.
- Task steps that add a plan file to git were skipped, because the plans were already committed. If wrong, a plan
  file is untracked, which `git status` shows at once.
