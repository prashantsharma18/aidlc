# Plan 2: The agent harness (Claude Code first)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (chosen by the owner for Plans 2–5) to implement this plan task by task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal.** Give every repository installed with the framework an enforced harness, as set out in guide Chapter 3 steps 1–9:
- a risk inventory;
- an effective permission policy that a repository can narrow but never loosen;
- a fail-closed pre-tool guard and post-tool check;
- Claude Code settings rendered from tool-neutral policy (permissions, sandbox, hooks, memory, plugin isolation);
- `aidlc doctor`;
- attack tests that prove each control blocks, both directly and through a live headless session.

**Architecture.**
- Hooks are standard-library Python scripts in `core/hooks/` that speak the generic hook contract. A thin Claude Code shim translates Claude's hook payloads to and from that contract.
- `aidlc render --tool claude-code` copies the hooks into the repository (`.aidlc/hooks/`, generated and protected). It writes their data file (`harness.json`) and generates `.claude/settings.json`.
- Generated non-Markdown files are tracked in a manifest (`.aidlc/generated.json`, path → sha256), so hand edits are detected and never overwritten.
- The task scope lives outside the repository at a path derived from the repository and branch. Both `aidlc scope` and the guard compute that path.

**Tech stack.**
- Python 3.12. The CLI may use the standard library, PyYAML and jsonschema. Hooks use the standard library only.
- Tests: `unittest`.
- Live attack tests: Claude Code 2.1.296 headless (`claude -p`), behind an opt-in Make target.

**Spec.**
- Design: `docs/design/2026-10-18-aidlc-framework-design.md`, §4.3 and §7.
- ADR: `docs/adr/0001-policy-as-code.md`.
- Sandbox evidence: `docs/verification/2026-10-18-sandbox-wsl2.md`.

**Out of scope.**
- The MCP gateway (platform layer; platform ADR 20 / M36).
- Skills and agents packaged as a plugin (Plan 4).
- `aidlc check`/`ci`, evals, observability shipping (Plan 3).

## Global constraints

- Hooks (`core/hooks/*.py`):
  - standard library only;
  - no network;
  - each run finishes in under 1 s;
  - every error path returns `deny` (pre) or `flag` (post);
  - the Claude shim exits 2 on any internal error.
- Claude Code hook entries set `"onFailure": "block"` and `"timeout": 10`. Requires Claude Code ≥ 2.1.295.
- A pre-hook "no objection" is **no output and exit 0**. Never print `permissionDecision: "allow"`.
- Unattended runs (`AIDLC_UNATTENDED=1`) turn every `ask` into `deny`.
- Secret paths are denied twice: by Read deny rules (the Read tool runs outside the sandbox) and by sandbox `filesystem.denyRead` (commands). This is the verified finding of 2026-10-18.
- Never overwrite a file a person wrote. Markdown and Python files carry a `Generated by aidlc` marker in their first 6 lines; JSON files are tracked by the manifest.
- `make test` makes no model calls and no network calls. Live tests run only with `make harness-live`.
- Tests that commit use `tests/helpers.py` (global git hooks disabled).
- British spelling in documents.

## Review focus

1. **Path tricks:** `src/../../.aidlc/hooks/harness.json`, an absolute path to a protected file, a symlink inside the repository pointing at a protected file, and a scope file planted inside the repository. Each must be denied. (Test: Task 3.)
2. **Command obfuscation:**
   - `git -C . push`, `FOO=1 git push`, `echo $(git push)` and backticks;
   - `bash -c 'git push'`, newline-separated commands and `rm -fr`.
   Each must be denied or asked, never allowed. (Test: Task 3.)
3. **Hook infrastructure failure:** missing or corrupt `harness.json`, missing scope, unreadable stdin, `python3` absent, timeout. Every case blocks and is logged. (Tests: Tasks 3, 5; live in Task 10.)
4. **Claude payload variants:** `MultiEdit` (`file_path`), `NotebookEdit` (`notebook_path`), MCP names with hyphens, `Bash` with `run_in_background`, a missing `tool_input`. Each gets the right class or fails closed. (Test: Task 5.)
5. **Re-render after a hand edit** of `.claude/settings.json` or a hook script: refused, not silently overwritten. (Test: Task 6.)

`cli/aidlc/harness.py`:
```python
"""The effective harness for one repository: the framework baseline (core/policy/permissions.yaml)
narrowed by the repository (.aidlc/permissions.yaml). A repository can add denials and asks
and remove allows; the only loosening (allow_add) needs a reason and an owner and is reported
by `aidlc doctor`. Deny always beats allow (guide 3 step 3)."""
from __future__ import annotations

import copy
import hashlib
import json
from pathlib import Path

import jsonschema
import yaml

from . import __version__
from .paths import framework_root
from .policy import PolicyError, load_policy, load_yaml
from .repo import load_config

KINDS = ("read", "edit", "shell", "tools")


class HarnessError(Exception):
    """The repository's harness configuration is invalid."""


def _dedupe(items: list[str]) -> list[str]:
    seen, out = set(), []
    for item in items:
        if item not in seen:
            seen.add(item)
            out.append(item)
    return out


def load_narrowing(repo: Path) -> dict:
    path = repo / ".aidlc" / "permissions.yaml"
    if not path.is_file():
        return {}
    try:
        text = path.read_text(encoding="utf-8").lstrip("﻿")
        data = yaml.safe_load(text) or {}
    except (OSError, yaml.YAMLError) as exc:
        raise HarnessError(f"{path}: cannot read: {exc}") from exc
    schema = json.loads((framework_root() / "core" / "schemas" /
                         "repo-permissions.schema.json").read_text(encoding="utf-8"))
    errors = sorted(jsonschema.Draft202012Validator(schema).iter_errors(data),
                    key=lambda e: list(map(str, e.absolute_path)))
    if errors:
        raise HarnessError("\n".join(
            f"{path}: {'/'.join(map(str, e.absolute_path)) or '<root>'}: {e.message}" for e in errors))
    return data


def effective_permissions(repo: Path) -> dict:
    try:
        base = copy.deepcopy(load_policy("permissions"))
    except PolicyError as exc:
        raise HarnessError(str(exc)) from exc
    base.pop("meta", None)
    n = load_narrowing(repo)
    for kind in KINDS:
        for section in ("deny", "ask", "allow"):
            base.setdefault(section, {}).setdefault(kind, [])
        base["deny"][kind] += n.get("deny_add", {}).get(kind, [])
        if kind != "read":
            base["ask"][kind] += n.get("ask_add", {}).get(kind, [])
        removed = set(n.get("allow_remove", {}).get(kind, []))
        base["allow"][kind] = [p for p in base["allow"][kind] if p not in removed]
    base["secret_paths"] += n.get("secret_paths_add", [])
    base["deny"]["read"] += n.get("secret_paths_add", [])
    base["protected_paths"] += n.get("protected_paths_add", [])
    base["deny"]["edit"] += n.get("protected_paths_add", [])
    base["allow_added"] = []
    for entry in n.get("allow_add", []):
        base["allow"][entry["kind"]].append(entry["pattern"])
        base["allow_added"].append(dict(entry))
    base["network_allow_add"] = list(n.get("network_allow_add", []))
    base["sandbox_allow_write_add"] = list(n.get("sandbox_allow_write_add", []))
    for section in ("deny", "ask", "allow"):
        for kind in KINDS:
            base[section][kind] = _dedupe(base[section][kind])
    base["secret_paths"] = _dedupe(base["secret_paths"])
    base["protected_paths"] = _dedupe(base["protected_paths"])
    return base


def map_tools(names: list[str], tool_names: dict[str, str]) -> tuple[list[str], list[str]]:
    mapped, unmapped = [], []
    for name in names:
        if name in tool_names:
            mapped.append(tool_names[name])
        else:
            unmapped.append(name)
    return mapped, unmapped


def harness_data(repo: Path) -> dict:
    eff = effective_permissions(repo)
    tool_names = load_config(repo).tool_names
    data = {
        "protected_paths": eff["protected_paths"],
        "shell_deny": eff["deny"]["shell"],
        "tool_deny": map_tools(eff["deny"]["tools"], tool_names)[0],
        "tool_ask": map_tools(eff["ask"]["tools"], tool_names)[0],
    }
    digest = hashlib.sha256(json.dumps(data, sort_keys=True).encode()).hexdigest()[:12]
    return {"version": f"{__version__}+{digest}", **data}
```

  - `current_branch(root: Path) -> str | None`
  - `scope_file(root: Path, branch: str) -> Path`:
    - `$AIDLC_SCOPE_FILE` if set;
    - otherwise `<AIDLC_HOME_DIR or ~/.aidlc>/scopes/<root.name>/<branch with "/" → "__">.scope`.
  - `load_scope(root: Path) -> list[str] | None`: `None` means no usable scope
  - `main() -> int`: reads stdin, prints the decision JSON, appends one JSONL record to `<AIDLC_LOG_DIR or ~/.aidlc/logs>/decisions.jsonl`
- Environment:
  - `AIDLC_HARNESS_FILE`: default `harness.json` next to the script
  - `AIDLC_UNATTENDED=1`: `ask` becomes `deny`
  - `AIDLC_SCOPE=off`: edit scope not enforced; refused when unattended; logged
  - `AIDLC_SCOPE_FILE`, `AIDLC_HOME_DIR`, `AIDLC_LOG_DIR`
- Tool classes in the event: `read`, `edit`, `shell`, `mcp`, `external`. Anything else is denied (`unknown-tool`).

#!/usr/bin/env python3
"""aidlc pre-tool guard (guide chapter 3, step 5). Standard library only; no network.

Generic contract (docs/adapters/interface.md):
  stdin   {"session": str, "call": str, "tool": "read|edit|shell|mcp|external", "args": {...}, "cwd": str}
  stdout  {"decision": "allow|ask|deny", "rule": str, "reason": str}
"allow" means "no objection": permissions and the sandbox still apply. Fails closed: any error,
unreadable input, missing harness data or missing task scope gives "deny".
"""
from __future__ import annotations

import datetime as _dt
import fnmatch
import json
import os
import re
import sys
from pathlib import Path

HERE = Path(__file__).resolve().parent
SECRET_RE = re.compile(r"(AKIA[0-9A-Z]{16}|ASIA[0-9A-Z]{16}|gh[pousr]_[A-Za-z0-9]{36,}"
                       r"|sk-ant-[A-Za-z0-9_-]{20,}|-----BEGIN [A-Z ]*PRIVATE KEY)")
SPLIT_RE = re.compile(r"&&|\|\||;|\|&|\||&|\n")
SUBST_RE = re.compile(r"\$\(([^()]*)\)|`([^`]*)`")
PIPE_TO_SHELL_RE = re.compile(r"\|\s*(sudo\s+)?(ba|z|da|k)?sh(\s|$)")
NESTED_RE = re.compile(r"^(bash|sh|zsh|dash)\s+-c\b|^eval\s")
GIT_OPTS_RE = re.compile(r"^git((\s+-C\s+\S+)|(\s+-c\s+\S+))+\s+")
ENV_PREFIX_RE = re.compile(r"^([A-Za-z_][A-Za-z0-9_]*=\S*\s+)+")


def _result(decision: str, rule: str, reason: str) -> dict:
    return {"decision": decision, "rule": rule, "reason": reason}


def _unattended() -> bool:
    return os.environ.get("AIDLC_UNATTENDED") == "1"


def _ask(rule: str, reason: str) -> dict:
    if _unattended():
        return _result("deny", rule, reason + " (unattended run: ask means deny)")
    return _result("ask", rule, reason)


def load_harness() -> dict:
    path = Path(os.environ.get("AIDLC_HARNESS_FILE") or HERE / "harness.json")
    data = json.loads(path.read_text(encoding="utf-8"))
    for key in ("protected_paths", "shell_deny", "tool_deny", "tool_ask"):
        if not isinstance(data.get(key), list):
            raise ValueError(f"harness data lacks '{key}'")
    return data


def matches(path: str, patterns: list[str], any_depth_names: bool = True) -> bool:
    for pat in patterns:
        if pat.startswith("~"):
            continue                          # home patterns apply outside the repository
        if fnmatch.fnmatchcase(path, pat):
            return True
        if pat.startswith("**/") and fnmatch.fnmatchcase(path, pat[3:]):
            return True
        if pat.endswith("/**") and path == pat[:-3]:
            return True
        if any_depth_names and "/" not in pat and fnmatch.fnmatchcase(path.rsplit("/", 1)[-1], pat):
            return True
    return False


def repo_root(start: Path) -> Path | None:
    current = start.resolve()
    for candidate in (current, *current.parents):
        if (candidate / ".git").exists():
            return candidate
    return None


def current_branch(root: Path) -> str | None:
    dotgit = root / ".git"
    if dotgit.is_file():                       # a worktree: ".git" names the real git dir
        text = dotgit.read_text(encoding="utf-8").strip()
        if not text.startswith("gitdir:"):
            return None
        gitdir = (root / text[len("gitdir:"):].strip()).resolve()
    else:
        gitdir = dotgit
    head = (gitdir / "HEAD").read_text(encoding="utf-8").strip()
    prefix = "ref: refs/heads/"
    return head[len(prefix):] if head.startswith(prefix) else None


def scope_file(root: Path, branch: str) -> Path:
    explicit = os.environ.get("AIDLC_SCOPE_FILE")
    if explicit:
        return Path(explicit).expanduser()
    home = Path(os.environ.get("AIDLC_HOME_DIR") or "~/.aidlc").expanduser()
    return home / "scopes" / root.name / (branch.replace("/", "__") + ".scope")


def load_scope(root: Path) -> list[str] | None:
    branch = current_branch(root)
    if not branch:
        return None
    path = scope_file(root, branch)
    if path.resolve().is_relative_to(root.resolve()) or not path.is_file():
        return None
    patterns = [line.strip() for line in path.read_text(encoding="utf-8").splitlines()
                if line.strip() and not line.lstrip().startswith("#")]
    return patterns or None


def _decide_edit(event: dict, data: dict) -> dict:
    raw = (event.get("args") or {}).get("path")
    if not isinstance(raw, str) or not raw:
        return _result("deny", "fail-safe", "edit without a path")
    cwd = Path(event.get("cwd") or os.getcwd())
    root = repo_root(cwd)
    if root is None:
        return _result("deny", "outside-repo", "not inside a git repository")
    target = Path(raw) if Path(raw).is_absolute() else cwd / raw
    resolved = Path(os.path.realpath(target))
    try:
        rel = resolved.relative_to(root.resolve()).as_posix()
    except ValueError:
        return _result("deny", "outside-repo", f"{raw} is outside the repository")
    if matches(rel, data["protected_paths"]):
        return _result("deny", "protected-path", f"{rel} is protected (harness, rules, CI, plans "
                       "or contracts). Do not work around it; describe the need in your notes.")
    if os.environ.get("AIDLC_SCOPE") == "off":
        if _unattended():
            return _result("deny", "no-scope", "AIDLC_SCOPE=off is refused in unattended runs")
        return _result("allow", "scope-off", "task scope switched off by AIDLC_SCOPE=off (logged)")
    scope = load_scope(root)
    if scope is None:
        branch = current_branch(root) or "<detached>"
        return _result("deny", "no-scope", f"no task scope for branch '{branch}': run "
                       f"`aidlc scope --branch {branch}` after the bundle is approved")
    if not matches(rel, scope, any_depth_names=False):
        return _result("deny", "outside-scope", f"{rel} is outside this task's MAY CHANGE list. "
                       "Stop and ask if the change is needed.")
    return _result("allow", "in-scope", "inside the task scope")


def _parts(command: str) -> list[str]:
    parts = []
    for inner in SUBST_RE.findall(command):
        parts += _parts(inner[0] or inner[1])
    for part in SPLIT_RE.split(command):
        part = part.strip().lstrip("(").strip()
        if part:
            part = ENV_PREFIX_RE.sub("", part)
            parts.append(GIT_OPTS_RE.sub("git ", part))
    return parts


def _decide_shell(event: dict, data: dict) -> dict:
    command = (event.get("args") or {}).get("command")
    if not isinstance(command, str) or not command.strip():
        return _result("deny", "fail-safe", "shell call without a command")
    if PIPE_TO_SHELL_RE.search(command):
        return _result("deny", "pipe-to-shell", "piping into a shell is not allowed")
    for part in _parts(command):
        for pat in data["shell_deny"]:
            if fnmatch.fnmatchcase(part, pat):
                return _result("deny", "shell-deny", f"'{part[:80]}' matches the denied pattern '{pat}'")
        if NESTED_RE.search(part):
            return _ask("nested-shell", "a nested shell hides its command; a person must read it")
    return _result("allow", "no-guarded-command", "no guarded command found")


def decide(event: dict) -> dict:
    try:
        data = load_harness()
    except Exception as exc:  # noqa: BLE001 - any failure here must block
        return _result("deny", "fail-safe", f"harness data unreadable ({type(exc).__name__}); "
                       "run `aidlc render --tool claude-code`")
    try:
        tool = event.get("tool")
        if tool == "read":
            return _result("allow", "read", "read-only; secrets are left to permissions and sandbox")
        if tool == "edit":
            return _decide_edit(event, data)
        if tool == "shell":
            return _decide_shell(event, data)
        if tool == "mcp":
            name = str((event.get("args") or {}).get("name", ""))
            if any(fnmatch.fnmatchcase(name, p) for p in data["tool_deny"]):
                return _result("deny", "tool-deny", f"{name} is denied by policy")
            if any(fnmatch.fnmatchcase(name, p) for p in data["tool_ask"]):
                return _ask("tool-ask", f"{name} needs a person's approval")
            return _result("allow", "integration", "integration call; permissions decide")
        if tool == "external":
            return _ask("external", "reaching outside the workspace needs a person's approval")
        return _result("deny", "unknown-tool", f"unknown tool class '{tool}'")
    except Exception as exc:  # noqa: BLE001
        return _result("deny", "fail-safe", f"guard error ({type(exc).__name__}); blocked to be safe")


def _log(event: dict, result: dict) -> None:
    try:
        try:
            version = load_harness().get("version", "unknown")
        except Exception:  # noqa: BLE001
            version = "unknown"
        args = event.get("args") or {}
        target = str(args.get("path") or args.get("command") or args.get("name") or args.get("url") or "")
        record = {"ts": _dt.datetime.now(_dt.timezone.utc).isoformat(timespec="seconds"),
                  "hook": "pre-tool-guard", "session": event.get("session"), "call": event.get("call"),
                  "harness": version, "tool": event.get("tool"),
                  "target": SECRET_RE.sub("[REDACTED]", target)[:200], **result}
        logdir = Path(os.environ.get("AIDLC_LOG_DIR") or "~/.aidlc/logs").expanduser()
        logdir.mkdir(parents=True, exist_ok=True)
        with (logdir / "decisions.jsonl").open("a", encoding="utf-8") as fh:
            fh.write(json.dumps(record) + "\n")
    except Exception:  # noqa: BLE001 - logging must never change the decision
        pass


def main() -> int:
    try:
        event = json.loads(sys.stdin.read())
        if not isinstance(event, dict):
            raise ValueError("event is not an object")
        result = decide(event)
    except Exception:  # noqa: BLE001
        event, result = {}, _result("deny", "fail-safe", "unreadable tool call")
    _log(event, result)
    print(json.dumps(result))
    return 0


if __name__ == "__main__":
    sys.exit(main())

#!/usr/bin/env python3
"""aidlc post-tool check (guide chapter 3 step 5; 9.5). Standard library only; no network.
Runs after a modifying or executing tool call. It cannot undo the action: it flags, and the
adapter shows the reason to the agent. Flags: credential-shaped output, files written outside
the task scope, an existing assertion changed or removed. Trusted CI is the real check; this is
the fast first line. Fails closed: errors give "flag"."""
from __future__ import annotations

import json
import os
import re
import subprocess
import sys
from pathlib import Path

sys.path.insert(0, str(Path(__file__).resolve().parent))
import guard  # noqa: E402  (same directory)

ASSERT_RE = re.compile(r"(expect\(|\bassert|Assert\.|\.Should\(|Should\.|\.toBe\(|\.toEqual\(|"
                       r"\.toMatch|\.toThrow|Verify\()")
TEST_FILE_RE = re.compile(r"(^|/)(test|tests|__tests__)/|\.(test|spec)\.[cm]?[jt]sx?$|Tests?\.cs$")


def _result(decision: str, rule: str, reason: str) -> dict:
    return {"decision": decision, "rule": rule, "reason": reason}


def _git(root: Path, *args: str) -> str:
    env = {k: v for k, v in os.environ.items() if not k.startswith("GIT_")}
    out = subprocess.run(["git", *args], cwd=root, capture_output=True, text=True, env=env, timeout=10)
    if out.returncode != 0:
        raise RuntimeError(f"git {' '.join(args)}: {out.stderr.strip()[:200]}")
    return out.stdout


def check(event: dict) -> dict:
    try:
        if guard.SECRET_RE.search(str(event.get("output") or "")):
            return _result("flag", "secret-in-output", "output contains something shaped like a "
                           "credential. Do not repeat it; stop and tell a person.")
        if event.get("tool") not in ("edit", "shell"):
            return _result("pass", "not-modifying", "read or integration call")
        root = guard.repo_root(Path(event.get("cwd") or os.getcwd()))
        if root is None:
            return _result("flag", "fail-safe", "not inside a git repository")
        base = _git(root, "merge-base", os.environ.get("AIDLC_BASE_REF") or "main", "HEAD").strip()
        changed = set(_git(root, "diff", "--no-renames", "--name-only", base).split())
        changed |= set(_git(root, "ls-files", "--others", "--exclude-standard").split())
        scope_off = os.environ.get("AIDLC_SCOPE") == "off" and os.environ.get("AIDLC_UNATTENDED") != "1"
        scope = None if scope_off else guard.load_scope(root)
        if scope is None and not scope_off:
            return _result("flag", "no-scope", "no readable task scope; changes cannot be checked")
        for path in sorted(changed):
            if scope is not None and not guard.matches(path, scope, any_depth_names=False):
                return _result("flag", "outside-scope", f"{path} was written outside the task's "
                               "MAY CHANGE list. Revert it, or stop and ask.")
            if TEST_FILE_RE.search(path) and _exists_at(root, base, path):
                removed = [line for line in _git(root, "diff", "--no-renames", "-U0", base, "--", path).splitlines()
                           if line.startswith("-") and not line.startswith("---") and ASSERT_RE.search(line)]
                if removed:
                    return _result("flag", "changed-assertion", f"an existing assertion in {path} was "
                                   f"changed or removed. Restore it, or stop and ask: {removed[0][:120]}")
        return _result("pass", "no-rule-broken", "no rule broken")
    except Exception as exc:  # noqa: BLE001 - fail closed
        return _result("flag", "fail-safe", f"post-tool check failed ({type(exc).__name__}); "
                       "treat the result as unchecked")


def _exists_at(root: Path, base: str, path: str) -> bool:
    env = {k: v for k, v in os.environ.items() if not k.startswith("GIT_")}
    return subprocess.run(["git", "cat-file", "-e", f"{base}:{path}"], cwd=root, env=env,
                          capture_output=True, timeout=10).returncode == 0


def main() -> int:
    try:
        event = json.loads(sys.stdin.read())
        if not isinstance(event, dict):
            raise ValueError("event is not an object")
        result = check(event)
    except Exception:  # noqa: BLE001
        event, result = {}, _result("flag", "fail-safe", "unreadable tool result")
    guard._log({**event, "hook": "post-tool-check"}, result)
    print(json.dumps(result))
    return 0


if __name__ == "__main__":
    sys.exit(main())
```

#!/usr/bin/env python3
"""Claude Code adapter shim: translates Claude Code hook payloads to the generic contract and
back. Usage: claude_shim.py pre|post. "No objection" is no output (never permissionDecision
"allow"). Any internal error exits 2, which Claude Code treats as a block; settings also set
onFailure: block so a crash or timeout blocks too."""
from __future__ import annotations

import json
import os
import sys
from pathlib import Path

CLASSES = {"Read": "read", "Glob": "read", "Grep": "read", "LS": "read",
           "Edit": "edit", "Write": "edit", "MultiEdit": "edit", "NotebookEdit": "edit",
           "Bash": "shell", "WebFetch": "external", "WebSearch": "external"}


def to_generic(payload: dict, phase: str) -> dict:
    name = str(payload.get("tool_name") or "")
    inp = payload.get("tool_input") or {}
    if name.startswith("mcp__"):
        tool, args = "mcp", {"name": name}
    else:
        tool = CLASSES.get(name, "unknown")
        if tool == "edit":
            args = {"path": inp.get("notebook_path") if name == "NotebookEdit" else inp.get("file_path")}
        elif tool == "shell":
            args = {"command": inp.get("command")}
        elif tool == "read":
            args = {"path": inp.get("file_path") or inp.get("path") or inp.get("pattern")}
        elif tool == "external":
            args = {"url": inp.get("url") or inp.get("query")}
        else:
            args = {}
    event = {"session": payload.get("session_id"), "call": payload.get("tool_use_id"),
             "tool": tool, "args": args, "cwd": payload.get("cwd") or os.getcwd()}
    if phase == "post":
        event["output"] = json.dumps(payload.get("tool_response"))[:200_000]
        event["hook"] = "post-tool-check"
    return event


def main(argv: list[str]) -> int:
    try:
        phase = argv[1] if len(argv) > 1 else ""
        if phase not in ("pre", "post"):
            raise ValueError(f"phase must be pre or post, got '{phase}'")
        sys.path.insert(0, str(Path(__file__).resolve().parent))
        import guard  # noqa: E402
        import post_check  # noqa: E402
        payload = json.loads(sys.stdin.read())
        if not isinstance(payload, dict):
            raise ValueError("payload is not an object")
        event = to_generic(payload, phase)
        if phase == "pre":
            result = guard.decide(event)
            guard._log(event, result)
            if result["decision"] in ("ask", "deny"):
                print(json.dumps({"hookSpecificOutput": {
                    "hookEventName": "PreToolUse", "permissionDecision": result["decision"],
                    "permissionDecisionReason": f"[aidlc {result['rule']}] {result['reason']}"}}))
            return 0
        result = post_check.check(event)
        guard._log(event, result)
        if result["decision"] == "flag":
            print(json.dumps({"decision": "block", "reason": f"[aidlc {result['rule']}] {result['reason']}"}))
        return 0
    except Exception as exc:  # noqa: BLE001 - exit 2 blocks in Claude Code
        print(f"aidlc hook failed ({type(exc).__name__}: {exc}); blocked to be safe", file=sys.stderr)
        return 2


if __name__ == "__main__":
    sys.exit(main(sys.argv))
```
