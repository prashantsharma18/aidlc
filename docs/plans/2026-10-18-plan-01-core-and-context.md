# Plan 1: Core and context engineering

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task by task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal.** Build the tool-neutral core of the AIDLC framework:
- a CLI;
- validated policies;
- stage-artefact templates;
- guide traceability;
- the context-engineering capability (repository scaffolding, the Claude Code rules renderer behind an adapter interface, drift checks, OpenWiki governance checks, task-scope generation).

**Architecture.**
- A Python 3.12 package in `cli/aidlc`, run through `bin/aidlc`. Each subcommand is one module under `cli/aidlc/commands/`.
- Policies are YAML in `core/policy/`, validated against JSON Schemas in `core/schemas/`.
- Templates and context standards are Markdown with YAML front matter, each declaring the guide sections it implements.
- Tool-specific output comes only from adapters in `cli/aidlc/adapters/`. Claude Code is implemented; Copilot is an extension point that raises a clear error.

**Tech stack.**
- Python 3.12.3, standard library only, plus two apt packages: PyYAML 6.0.1 (`python3-yaml`) and jsonschema 4.10.3 (`python3-jsonschema`).
- Tests: `unittest`, with git through `subprocess`.

**Spec.** `docs/design/2026-10-18-aidlc-framework-design.md` (approved 2026-10-18). Read §3–§6 before starting.

**Roadmap.** This is plan 1 of 5:
1. Core and context (this plan).
2. Harness: guard and post-check hooks, Claude Code plugin, settings, sandbox and permission rendering, attack tests.
3. Verification: `aidlc check`/`ci`, evals, AI review, observability.
4. Stage skills and agent roles.
5. Demo workspace and the cross-repository change.

## Global constraints

- Python `>=3.12`. Runtime imports only from the standard library, `yaml` and `jsonschema`. No pip install step.
- Run from the framework root with `bin/aidlc` (sets `PYTHONPATH=cli`). Tests run with `make test`.
- All text files UTF-8, LF line endings, a trailing newline. Parsers accept CRLF and a BOM on input.
- **Fail closed.** A missing file, unreadable input, unknown value or schema violation is an error with exit code 1 (findings) or 2 (usage), never a silent pass.
- **Never overwrite a file a person wrote.** Generated files start with `<!-- Generated by aidlc` (Markdown) or `# Generated by aidlc` (YAML/text). Only files carrying that marker may be rewritten.
- **Guide traceability.** Every policy has `meta.guide`; every template and context standard has front matter `guide:`. Values match `^(1[0-6]|[1-9])(\.\d+)?( (step \d+|[A-D]\d?))?$`.
- Tests that create git commits pass `-c core.hooksPath=/dev/null`. The user's global hooks path is `~/lab/git-hooks`.
- British spelling in documents, matching the guide.

## Review focus

1. `init-repo` or `render` run on a repository that already has a hand-written `AGENTS.md` or `CLAUDE.md`. Nothing is overwritten. `render` refuses with a message saying where the content should go. (Tests: Task 7, Task 8.)
2. The user's global `core.hooksPath` running during test commits. The test helper disables it. (Test: Task 1 helper, used everywhere.)
3. CRLF line endings and a UTF-8 BOM in bundle, rules and template files. Parsed the same as LF. (Tests: Task 4, Task 9, Task 11.)
4. Code identifiers and placeholders in backticks (`src/auth/<feature>/`, `req.ip`, `config.get()`, `flags.isEnabled`) are not reported as missing paths, while a real stale path is. (Test: Task 9.)
5. The CLI run from a subdirectory of a repository, or outside any git repository. Subdirectories resolve to the repository root. Outside a repository is a clear error with exit 2. (Tests: Task 7, Task 9.)

"""Shared test helpers. Commits disable the user's global git hooks."""
from __future__ import annotations

import contextlib
import io
import os
import subprocess
import tempfile
from pathlib import Path

GIT = ["git", "-c", "core.hooksPath=/dev/null", "-c", "user.name=aidlc-test",
       "-c", "user.email=aidlc-test@example.invalid", "-c", "commit.gpgsign=false"]


def git(root: Path, *args: str) -> str:
    result = subprocess.run([*GIT, *args], cwd=root, check=True,
                            capture_output=True, text=True)
    return result.stdout.strip()


class TempRepo:
    """A throwaway git repository. Files are committed when given."""

    def __init__(self, files: dict[str, str] | None = None):
        self._files = files or {}
        self._tmp: tempfile.TemporaryDirectory[str] | None = None

    def __enter__(self) -> Path:
        self._tmp = tempfile.TemporaryDirectory(prefix="aidlc-test-")
        root = Path(self._tmp.name)
        git(root, "init", "-q", "-b", "main")
        for rel, content in self._files.items():
            path = root / rel
            path.parent.mkdir(parents=True, exist_ok=True)
            path.write_text(content, encoding="utf-8")
        if self._files:
            git(root, "add", "-A")
            git(root, "commit", "-q", "-m", "fixture")
        return root

    def __exit__(self, *exc: object) -> None:
        assert self._tmp is not None
        self._tmp.cleanup()


def run_cli(*args: str, cwd: Path | None = None) -> tuple[int, str, str]:
    """Run aidlc.cli.main in-process; returns (exit code, stdout, stderr)."""
    from aidlc.cli import main

    out, err = io.StringIO(), io.StringIO()
    old = Path.cwd()
    try:
        if cwd is not None:
            os.chdir(cwd)
        with contextlib.redirect_stdout(out), contextlib.redirect_stderr(err):
            try:
                code = main(list(args))
            except SystemExit as exc:  # argparse exits on --help/--version/errors
                code = int(exc.code or 0)
    finally:
        os.chdir(old)
    return code, out.getvalue(), err.getvalue()
```

"""Where the framework lives, and where the repository being worked on lives."""
from __future__ import annotations

import os
from pathlib import Path


def framework_root() -> Path:
    """The framework checkout. AIDLC_HOME overrides it (used by tests)."""
    override = os.environ.get("AIDLC_HOME")
    if override:
        return Path(override).resolve()
    return Path(__file__).resolve().parents[2]


def find_repo_root(start: Path) -> Path:
    """The nearest directory at or above `start` that holds a .git entry."""
    current = start.resolve()
    for candidate in (current, *current.parents):
        if (candidate / ".git").exists():
            return candidate
    raise FileNotFoundError(f"not inside a git repository: {start}")
```

"""Command-line entry point. Subcommand modules register themselves with @command."""
from __future__ import annotations

import argparse
from collections.abc import Callable, Sequence

from . import __version__

Registrar = Callable[[argparse._SubParsersAction], None]
_REGISTRARS: list[Registrar] = []


def command(fn: Registrar) -> Registrar:
    """Register a function that adds one subcommand to the parser."""
    _REGISTRARS.append(fn)
    return fn


def build_parser() -> argparse.ArgumentParser:
    from . import commands  # noqa: F401  importing registers every subcommand

    parser = argparse.ArgumentParser(
        prog="aidlc", description="AI-native SDLC framework (From Intent to Verified Change)")
    parser.add_argument("--version", action="version", version=f"aidlc {__version__}")
    sub = parser.add_subparsers(dest="command", metavar="<command>")
    for register in _REGISTRARS:
        register(sub)
    return parser


def main(argv: Sequence[str] | None = None) -> int:
    parser = build_parser()
    args = parser.parse_args(argv)
    func = getattr(args, "func", None)
    if func is None:
        parser.print_help()
        return 2
    return int(func(args) or 0)
```

`cli/aidlc/policy.py`:
```python
"""Load YAML policies and validate them. Every policy has a `meta` block (owner,
review date, guide sections) and its own JSON Schema in core/schemas/."""
from __future__ import annotations

import json
from pathlib import Path
from typing import Any

import jsonschema
import yaml

from .paths import framework_root


class PolicyError(Exception):
    """A policy cannot be read or does not match its schema."""


def load_yaml(path: Path) -> Any:
    try:
        text = path.read_text(encoding="utf-8").lstrip("﻿")
        data = yaml.safe_load(text)
    except (OSError, yaml.YAMLError) as exc:
        raise PolicyError(f"{path}: cannot read: {exc}") from exc
    if data is None:
        raise PolicyError(f"{path}: empty")
    return data


def _schema(root: Path, name: str) -> dict:
    path = root / "core" / "schemas" / f"{name}.schema.json"
    if not path.is_file():
        raise PolicyError(f"no schema {path.name} for policy '{name}'")
    return json.loads(path.read_text(encoding="utf-8"))


def _errors(schema: dict, data: Any, label: str) -> list[str]:
    validator = jsonschema.Draft202012Validator(schema)
    out = []
    for err in sorted(validator.iter_errors(data), key=lambda e: list(map(str, e.absolute_path))):
        where = "/".join(str(p) for p in err.absolute_path) or "<root>"
        out.append(f"{label}: {where}: {err.message}")
    return out


def _check(root: Path, name: str, data: Any, path: Path) -> list[str]:
    label = str(path.relative_to(root)) if path.is_relative_to(root) else str(path)
    if not isinstance(data, dict) or "meta" not in data:
        return [f"{label}: <root>: 'meta' is a required property"]
    problems = _errors(_schema(root, "meta"), data["meta"], f"{label} meta")
    problems += _errors(_schema(root, name), data, label)
    if isinstance(data["meta"], dict) and data["meta"].get("id") not in (None, f"policy-{name}"):
        problems.append(f"{label}: meta/id: expected 'policy-{name}'")
    return problems


def load_policy(name: str, root: Path | None = None) -> dict:
    root = root or framework_root()
    path = root / "core" / "policy" / f"{name}.yaml"
    data = load_yaml(path)
    problems = _check(root, name, data, path)
    if problems:
        raise PolicyError("\n".join(problems))
    return data


def validate_all(root: Path | None = None) -> list[str]:
    root = root or framework_root()
    problems: list[str] = []
    paths = sorted((root / "core" / "policy").glob("*.yaml"))
    if not paths:
        return [f"no policies found under {root / 'core' / 'policy'}"]
    for path in paths:
        name = path.stem
        try:
            problems += _check(root, name, load_yaml(path), path)
        except PolicyError as exc:
            problems.append(f"{path.name}: {exc}")
    return problems
```

```python
"""Stage-artefact templates: Markdown with YAML front matter declaring id, title, stage,
guide sections and the {{FIELDS}} the body uses."""
from __future__ import annotations

import re
from dataclasses import dataclass
from pathlib import Path

import yaml

from .paths import framework_root

_FRONT = re.compile(r"\A---\n(.*?)\n---\n", re.S)
_VAR = re.compile(r"\{\{([A-Z][A-Z0-9_]*)\}\}")
_REQUIRED = ("id", "title", "stage", "guide", "fields")


class TemplateError(Exception):
    """A template is malformed, missing a value, or would overwrite a file."""


@dataclass(frozen=True)
class Template:
    id: str
    title: str
    stage: str
    guide: list[str]
    fields: list[str]
    body: str
    path: Path


def parse_front_matter(text: str, path: Path) -> tuple[dict, str]:
    text = text.lstrip("﻿").replace("\r\n", "\n")
    match = _FRONT.match(text)
    if not match:
        raise TemplateError(f"{path}: missing front matter")
    try:
        meta = yaml.safe_load(match.group(1)) or {}
    except yaml.YAMLError as exc:
        raise TemplateError(f"{path}: invalid front matter: {exc}") from exc
    if not isinstance(meta, dict):
        raise TemplateError(f"{path}: front matter must be a mapping")
    return meta, text[match.end():]


def _dir(root: Path | None) -> Path:
    return (root or framework_root()) / "core" / "templates"


def _from_path(path: Path) -> Template:
    meta, body = parse_front_matter(path.read_text(encoding="utf-8"), path)
    for key in _REQUIRED:
        if key not in meta:
            raise TemplateError(f"{path}: front matter lacks '{key}'")
    if meta["id"] != path.stem:
        raise TemplateError(f"{path}: id '{meta['id']}' does not match file name")
    undeclared = set(_VAR.findall(body)) - set(meta["fields"])
    if undeclared:
        raise TemplateError(f"{path}: body uses undeclared fields {sorted(undeclared)}")
    return Template(meta["id"], meta["title"], meta["stage"], list(meta["guide"]),
                    list(meta["fields"]), body, path)


def load_template(tid: str, root: Path | None = None) -> Template:
    path = _dir(root) / f"{tid}.md"
    if not path.is_file():
        raise TemplateError(f"unknown template '{tid}' (looked for {path})")
    return _from_path(path)


def list_templates(root: Path | None = None) -> list[Template]:
    return [_from_path(p) for p in sorted(_dir(root).glob("*.md"))]


def render(t: Template, values: dict[str, str]) -> str:
    missing = [f for f in t.fields if f not in values]
    if missing:
        raise TemplateError(f"template '{t.id}' needs values for: {', '.join(missing)}")
    body = _VAR.sub(lambda m: values[m.group(1)], t.body)
    return f"<!-- aidlc template: {t.id} -->\n{body}"


def write_new(t: Template, values: dict[str, str], out: Path) -> Path:
    if out.exists():
        raise TemplateError(f"{out} exists; refusing to overwrite")
    text = render(t, values)
    out.parent.mkdir(parents=True, exist_ok=True)
    out.write_text(text, encoding="utf-8")
    return out
```

import re
from dataclasses import dataclass
from pathlib import Path

from .paths import framework_root
from .policy import PolicyError, load_yaml
from .templates import TemplateError, parse_front_matter

CHAPTERS = {
    1: "The AI-native lifecycle, end to end", 2: "Context engineering", 3: "The agent harness",
    4: "Understanding a codebase before you change it", 5: "Intent to specification",
    6: "Architecture, boundaries and contracts", 7: "Planning and task design",
    8: "Building with an agent", 9: "Testing AI-written code",
    10: "Evaluating agents and AI workflows", 11: "Review, approval and release",
    12: "Operate, measure and improve", 13: "Security and guardrails",
    14: "Changes that span repositories", 15: "Modernising legacy systems",
    16: "Your workflow: individual, team and organisation",
}
GUIDE_RE = re.compile(r"^(1[0-6]|[1-9])(\.\d+)?( (step \d+|[A-D]\d?))?$")
LINK_RE = re.compile(r"\]\(([^)\s]+)\)")
HEADER = "<!-- Generated by aidlc trace. Do not edit: run `bin/aidlc trace`. -->\n"


@dataclass(frozen=True)
class Element:
    id: str
    kind: str
    path: str
    guide: list[str]


def _guide_problems(guide: object, label: str) -> list[str]:
    if not isinstance(guide, list) or not guide:
        return [f"{label}: no guide sections declared"]
    return [f"{label}: bad guide reference '{g}'" for g in guide
            if not isinstance(g, str) or not GUIDE_RE.match(g)]


def collect(root: Path | None = None) -> tuple[list[Element], list[str]]:
    root = root or framework_root()
    core = root / "core"
    elements: list[Element] = []
    problems: list[str] = []

    for path in sorted((core / "policy").glob("*.yaml")):
        rel = str(path.relative_to(root))
        try:
            meta = load_yaml(path).get("meta", {})
        except (PolicyError, AttributeError) as exc:
            problems.append(f"{rel}: {exc}")
            continue
        problems += _guide_problems(meta.get("guide"), rel)
        elements.append(Element(meta.get("id", path.stem), "policy", rel, list(meta.get("guide") or [])))

    md_sources = [("template", sorted((core / "templates").glob("*.md")), "guide"),
                  ("context", sorted(p for p in (core / "context").rglob("*.md")
                                     if p.name not in {"README.md", "INSTRUCTIONS.md"}), "guide"),
                  ("skill", sorted((core / "skills").glob("*/SKILL.md")), "metadata.guide")]
    for kind, paths, key in md_sources:
        for path in paths:
            rel = str(path.relative_to(root))
            try:
                meta, _ = parse_front_matter(path.read_text(encoding="utf-8"), path)
            except TemplateError as exc:
                problems.append(f"{rel}: {exc}")
                continue
            guide = meta.get("metadata", {}).get("guide") if key == "metadata.guide" else meta.get("guide")
            problems += _guide_problems(guide, rel)
            ident = meta.get("id") or meta.get("name") or path.stem
            elements.append(Element(str(ident), kind, rel, list(guide or [])))
    return sorted(elements, key=lambda e: (e.kind, e.id)), problems


def render_traceability(elements: list[Element]) -> str:
    lines = [HEADER, "# Traceability", "",
             "Every framework element and the guide sections it implements. The guide is",
             "the primary source (`~/demos/guide`); sections are written as chapter.section.", "",
             "## By chapter", "", "| Chapter | Title | Elements |", "|---|---|---|"]
    for n, title in CHAPTERS.items():
        ids = sorted({e.id for e in elements if any(g.split(".")[0].split(" ")[0] == str(n)
                                                   for g in e.guide)})
        lines.append(f"| {n} | {title} | {', '.join(ids) if ids else '(none yet)'} |")
    lines += ["", "## By element", "", "| Element | Kind | File | Guide |", "|---|---|---|---|"]
    for e in elements:
        lines.append(f"| {e.id} | {e.kind} | `{e.path}` | {', '.join(e.guide)} |")
    return "\n".join(lines) + "\n"


def render_tiers_table(root: Path | None = None) -> str:
    root = root or framework_root()
    data = load_yaml(root / "core" / "policy" / "tiers.yaml")
    tiers = data["tiers"]
    rows = [("Typical change", "typical"), ("Spec", "spec"), ("Design", "design"),
            ("Plan", "plan"), ("Verification", "verification"), ("Approvals", "approvals"),
            ("Agent autonomy", "autonomy"), ("Release", "release"),
            ("Evidence pack items", "evidence_pack")]
    head = "| | " + " | ".join(f"Tier {t['id']} · {t['name']}" for t in tiers) + " |"
    lines = [HEADER.replace("aidlc trace.", "aidlc trace from core/policy/tiers.yaml."),
             "# Risk tiers (generated)", "", data["rule"], "", head,
             "|---|" + "---|" * len(tiers)]
    for label, key in rows:
        cells = []
        for t in tiers:
            value = t[key]
            cells.append(", ".join(map(str, value)) if isinstance(value, list) else str(value))
        lines.append(f"| {label} | " + " | ".join(c or "none (notes in the PR)" for c in cells) + " |")
    return "\n".join(lines) + "\n"


FENCE_RE = re.compile(r"^(```|~~~).*?^\1", re.S | re.M)
INLINE_CODE_RE = re.compile(r"`[^`\n]*`")


def check_links(root: Path | None = None) -> list[str]:
    """Relative Markdown links must resolve. Links inside code (fenced or inline) are
    examples, not links, and are ignored."""
    root = root or framework_root()
    problems = []
    files = sorted((root / "docs").rglob("*.md")) if (root / "docs").is_dir() else []

            if target_path and not (path.parent / target_path).exists():
                problems.append(f"{path.relative_to(root)}: broken link {target}")
    return problems

    root = root or framework_root()
    elements, _ = collect(root)

"""Repository configuration (.aidlc/config.yaml) and Procedure A scaffolding."""
from __future__ import annotations

from dataclasses import dataclass, field
from datetime import date
from pathlib import Path

import yaml

from .paths import framework_root
from .policy import load_yaml
from .templates import load_template, render

CONFIG = Path(".aidlc/config.yaml")
GENERATED_YAML = "# Generated by aidlc init-repo. Owned by this repository: edit freely.\n"


@dataclass
class RepoConfig:
    name: str
    owner: str
    profile: str
    purpose: str
    commands: dict[str, str] = field(default_factory=dict)
    check_steps: list[str] = field(default_factory=list)
    context: dict = field(default_factory=dict)


def load_config(repo: Path) -> RepoConfig:
    path = repo / CONFIG
    if not path.is_file():
        raise FileNotFoundError(f"{path} not found: run `aidlc init-repo` first")
    data = load_yaml(path)
    ctx = {"rules_file": "AGENTS.md", "map": "docs/codebase-map.md", "review_interval_days": 30}
    ctx.update(data.get("context") or {})
    return RepoConfig(data["name"], data["owner"], data["profile"], data.get("purpose", ""),
                      dict(data.get("commands") or {}), list(data.get("check_steps") or []), ctx)


def _write(repo: Path, rel: str, text: str, report: list[tuple[str, str]]) -> None:
    path = repo / rel
    if path.exists():
        report.append((rel, "skipped (exists)"))
        return
    path.parent.mkdir(parents=True, exist_ok=True)
    path.write_text(text, encoding="utf-8")
    report.append((rel, "created"))


def init_repo(repo: Path, name: str, owner: str, profile: str, purpose: str,
              today: date) -> list[tuple[str, str]]:
    profiles = load_yaml(framework_root() / "core" / "context" / "profiles.yaml")
    if profile not in profiles:
        raise ValueError(f"unknown profile '{profile}'; choose from {', '.join(profiles)}")
    chosen = profiles[profile]
    ctx = framework_root() / "core" / "context"
    report: list[tuple[str, str]] = []

    config = {"name": name, "owner": owner, "profile": profile, "purpose": purpose,
              "commands": chosen["commands"], "check_steps": chosen["check_steps"],
              "context": {"rules_file": "AGENTS.md", "map": "docs/codebase-map.md",
                          "review_interval_days": 30},
              "openwiki": {"adopted": False}}
    _write(repo, str(CONFIG), GENERATED_YAML + yaml.safe_dump(config, sort_keys=False), report)

    agents = render(load_template("agents-md"), {"NAME": name, "PURPOSE": purpose,
                                                 "OWNER": owner, "CHECK_COMMAND": "aidlc check"})
    _write(repo, "AGENTS.md", agents, report)

    cmap = render(load_template("codebase-map"), {"NAME": name, "OWNER": owner,
                                                  "DATE": today.isoformat()})
    _write(repo, "docs/codebase-map.md", cmap, report)

    _write(repo, ".aidlc/rules/README.md",
           "<!-- Generated by aidlc init-repo. -->\n# Folder rules\n\n"
           "One file per area: front matter `paths:` (globs) and the rules as Markdown.\n"
           "Render with `aidlc render --tool claude-code`. Standard: "
           "core/context/standards/folder-rules.md in the framework.\n", report)
    _write(repo, ".aidlc/probe.yaml", (ctx / "probe.yaml.tmpl").read_text(encoding="utf-8"), report)
    _write(repo, ".openwikiignore",
           (ctx / "openwiki" / "openwikiignore.baseline").read_text(encoding="utf-8"), report)
    _write(repo, "plans/approved-bundles.txt",
           "# Generated by aidlc init-repo. One approved task bundle per line, appended on main:\n"
           "# <branch> <commit>:<bundle path> <approver> <YYYY-MM-DD>\n", report)
    return report

"""The adapter contract: render tool-neutral core and repository sources into one tool's
configuration. Only adapters know tool file names. See docs/adapters/interface.md."""
from __future__ import annotations

from dataclasses import dataclass
from pathlib import Path
from typing import Protocol

GENERATED_MARK = "<!-- Generated by aidlc"


class AdapterNotImplemented(Exception):
    """The adapter exists as an extension point but this function is not built yet."""


@dataclass(frozen=True)
class RenderedFile:
    path: str      # relative to the repository root, POSIX separators
    content: str


class Adapter(Protocol):
    name: str

    def render_rules(self, repo: Path) -> list[RenderedFile]: ...

    def render_folder_rules(self, repo: Path) -> list[RenderedFile]: ...


def _is_generated(text: str) -> bool:
    """Generated files carry the marker on one of their first lines (rule files start
    with YAML front matter, so the marker follows it)."""
    return any(line.startswith(GENERATED_MARK) for line in text.splitlines()[:6])


def write_rendered(repo: Path, files: list[RenderedFile], check: bool) -> list[str]:
    """Write generated files, or with check=True report what is missing or stale.
    A file that exists without the generated marker is never overwritten."""
    problems = []
    for f in files:
        target = repo / f.path
        current = target.read_text(encoding="utf-8") if target.is_file() else None
        if current is not None and not _is_generated(current):
            problems.append(f"{f.path}: exists and was not generated by aidlc; move its content "
                            f"to AGENTS.md or .aidlc/ and delete it, then render again")
            continue
        if current == f.content:
            continue
        if check:
            problems.append(f"{f.path}: {'missing' if current is None else 'stale'} "
                            f"(run aidlc render)")
            continue
        target.parent.mkdir(parents=True, exist_ok=True)
        target.write_text(f.content, encoding="utf-8")
    return problems
```

"""Claude Code adapter: CLAUDE.md imports AGENTS.md; folder rules become .claude/rules/."""
from __future__ import annotations

from pathlib import Path

from ..templates import TemplateError, parse_front_matter
from .base import RenderedFile

RULES_HEADER = ("<!-- Generated by aidlc render (claude-code). Do not edit: change AGENTS.md "
                "or .aidlc/claude.md, then run `aidlc render --tool claude-code`. -->\n")


class ClaudeCodeAdapter:
    name = "claude-code"

    def render_rules(self, repo: Path) -> list[RenderedFile]:
        text = RULES_HEADER + "@AGENTS.md\n"
        extra = repo / ".aidlc" / "claude.md"
        if extra.is_file():
            body = extra.read_text(encoding="utf-8").lstrip("﻿").replace("\r\n", "\n")
            text += "\n" + body.rstrip("\n") + "\n"
        return [RenderedFile("CLAUDE.md", text)]

    def render_folder_rules(self, repo: Path) -> list[RenderedFile]:
        out = []
        for src in sorted((repo / ".aidlc" / "rules").glob("*.md")):
            if src.name == "README.md":
                continue
            try:
                meta, body = parse_front_matter(src.read_text(encoding="utf-8"), src)
            except TemplateError as exc:
                raise ValueError(str(exc)) from exc
            paths = meta.get("paths")
            if not isinstance(paths, list) or not paths or not all(isinstance(p, str) for p in paths):
                raise ValueError(f"{src}: front matter needs 'paths:' as a non-empty list of globs")
            front = "---\npaths:\n" + "".join(f'  - "{p}"\n' for p in paths) + "---\n"
            note = (f"<!-- Generated by aidlc render (claude-code) from .aidlc/rules/{src.name}. "
                    "Do not edit. -->\n")
            out.append(RenderedFile(f".claude/rules/{src.name}",
                                    front + note + body.rstrip("\n") + "\n"))
        return out

from __future__ import annotations

from dataclasses import dataclass
from typing import Literal


@dataclass(frozen=True)
class Finding:
    level: Literal["FAIL", "WARN"]
    file: str
    line: int
    message: str

    def __str__(self) -> str:
        where = f"{self.file}:{self.line}" if self.line else self.file
        return f"{self.level} {where} {self.message}"


def report(findings: list[Finding], name: str) -> int:
    for f in findings:
        print(f)
    fails = sum(f.level == "FAIL" for f in findings)
    print(f"{name}: {fails} fail, {len(findings) - fails} warn")
    return 1 if fails else 0

```python
"""Context drift (guide 2.8 A7): rules files and the codebase map must name things that
exist, stay within their line budgets, and carry an owner and a fresh verification date."""
from __future__ import annotations

import json
import re
import subprocess
from datetime import date
from pathlib import Path

from .findings import Finding

SPAN = re.compile(r"`([^`\n]+)`")
EXTS = {"md", "json", "yaml", "yml", "ts", "tsx", "js", "mjs", "cjs", "cs", "csproj", "sln",
        "slnx", "py", "sh", "toml", "txt", "xml", "props", "targets", "sql", "html", "css",
        "lock", "cfg", "ini"}
FORBIDDEN = set(" <>{}()$~")
OPENWIKI = re.compile(r"<!-- OPENWIKI:START -->.*?<!-- OPENWIKI:END -->", re.S)
VERIFIED = re.compile(r"Last verified:\s*(\d{4}-\d{2}-\d{2}),\s*against commit\s+([0-9a-f]{7,40})")


def _read(path: Path) -> str:
    return path.read_text(encoding="utf-8").lstrip("﻿").replace("\r\n", "\n")


def _is_path(span: str) -> bool:
    if any(ch in FORBIDDEN for ch in span) or span.startswith(("/", "http", "-", "@")):
        return False
    if "/" in span:
        return True
    return "." in span and span.rsplit(".", 1)[1] in EXTS


def _exists(repo: Path, span: str) -> bool:
    if any(ch in span for ch in "*?["):
        return any(repo.glob(span.rstrip("/")))
    target = repo / span
    return target.is_dir() if span.endswith("/") else target.exists()


def _aidlc_subcommands() -> set[str]:
    from ..cli import build_parser
    parser = build_parser()
    for action in parser._subparsers._group_actions:  # argparse internals: the subparser action
        return set(action.choices)
    return set()


def _command_findings(repo: Path, rel: str, lineno: int, span: str,
                      subcommands: set[str]) -> list[Finding]:
    words = span.split()
    out = []
    if words[:2] == ["npm", "run"] and len(words) >= 3:
        pkg = repo / "package.json"
        scripts = json.loads(_read(pkg)).get("scripts", {}) if pkg.is_file() else {}
        if words[2] not in scripts:
            out.append(Finding("FAIL", rel, lineno, f"npm script '{words[2]}' not in package.json"))
    elif words[0] == "make" and len(words) >= 2:
        makefile = repo / "Makefile"
        text = _read(makefile) if makefile.is_file() else ""
        if not re.search(rf"^{re.escape(words[1])}\s*:", text, re.M):
            out.append(Finding("FAIL", rel, lineno, f"make target '{words[1]}' not in Makefile"))
    elif words[0] in ("aidlc", "bin/aidlc") and len(words) >= 2 and not words[1].startswith("-"):
        if words[1] not in subcommands:
            out.append(Finding("FAIL", rel, lineno, f"aidlc subcommand '{words[1]}' does not exist"))
    return out


def _scan(repo: Path, path: Path, subcommands: set[str]) -> list[Finding]:
    rel = str(path.relative_to(repo))
    findings = []
    for lineno, line in enumerate(_read(path).split("\n"), start=1):
        for span in SPAN.findall(line):
            span = span.strip()
            if " " in span:
                findings += _command_findings(repo, rel, lineno, span, subcommands)
            elif _is_path(span) and not _exists(repo, span):
                findings.append(Finding("FAIL", rel, lineno, f"names '{span}', which does not exist"))
    return findings


def _commit_exists(repo: Path, sha: str) -> bool:
    result = subprocess.run(["git", "cat-file", "-e", f"{sha}^{{commit}}"], cwd=repo,
                            capture_output=True)
    return result.returncode == 0


def check_context_drift(repo: Path, today: date) -> list[Finding]:
    interval = 30
    rules_file, map_file = "AGENTS.md", "docs/codebase-map.md"
    cfg_path = repo / ".aidlc" / "config.yaml"
    if cfg_path.is_file():
        from ..repo import load_config
        ctx = load_config(repo).context
        interval = int(ctx.get("review_interval_days", 30))
        rules_file, map_file = ctx.get("rules_file", rules_file), ctx.get("map", map_file)

    findings: list[Finding] = []
    subcommands = _aidlc_subcommands()
    sources = [repo / rules_file, repo / "CLAUDE.md", repo / map_file,
               *sorted((repo / ".aidlc" / "rules").glob("*.md"))]
    if not (repo / rules_file).is_file():
        findings.append(Finding("FAIL", rules_file, 0, "rules file missing"))
    for path in sources:
        if path.is_file() and path.name != "README.md":
            findings += _scan(repo, path, subcommands)

    if (repo / rules_file).is_file():
        n = len(OPENWIKI.sub("", _read(repo / rules_file)).rstrip("\n").split("\n"))
        if n > 200:
            findings.append(Finding("FAIL", rules_file, 0, f"{n} lines; the budget is 200"))
        elif n > 80:
            findings.append(Finding("WARN", rules_file, 0, f"{n} lines; aim for 80 or fewer"))
    claude = repo / "CLAUDE.md"
    if claude.is_file() and len(_read(claude).rstrip("\n").split("\n")) > 40:
        findings.append(Finding("FAIL", "CLAUDE.md", 0, "more than 40 lines; keep it thin"))

    cmap = repo / map_file
    if not cmap.is_file():
        findings.append(Finding("FAIL", map_file, 0, "codebase map missing"))
        return findings
    text = _read(cmap)
    if "Owner:" not in text:
        findings.append(Finding("FAIL", map_file, 0, "no 'Owner:' line"))
    match = VERIFIED.search(text)
    if not match:
        findings.append(Finding("FAIL", map_file, 0,
                                "no 'Last verified: YYYY-MM-DD, against commit <sha>' line"))
        return findings
    age = (today - date.fromisoformat(match.group(1))).days
    if age > interval:
        findings.append(Finding("WARN", map_file, 0,
                                f"last verified {age} days ago, older than {interval}"))
    if not _commit_exists(repo, match.group(2)):
        findings.append(Finding("FAIL", map_file, 0, f"commit {match.group(2)} is not in this repository"))
    return findings

"""OpenWiki governance (design §6.4): the managed block in AGENTS.md stays a short pointer,
never appears in CLAUDE.md, and the ignore file keeps the framework baseline."""
from __future__ import annotations

from pathlib import Path

from ..paths import framework_root
from .findings import Finding

START, END = "<!-- OPENWIKI:START -->", "<!-- OPENWIKI:END -->"


def _read(path: Path) -> str:
    return path.read_text(encoding="utf-8").lstrip("﻿").replace("\r\n", "\n")


def _block(text: str, rel: str) -> tuple[list[str] | None, list[Finding]]:
    starts, ends = text.count(START), text.count(END)
    if starts == 0 and ends == 0:
        return None, []
    if starts != 1 or ends != 1 or text.index(START) > text.index(END):
        return None, [Finding("FAIL", rel, 0, "OPENWIKI markers are not one ordered START/END pair")]
    inner = text[text.index(START) + len(START):text.index(END)]
    return [line for line in inner.split("\n") if line.strip()], []


def check_openwiki(repo: Path, max_lines: int = 15) -> list[Finding]:
    findings: list[Finding] = []
    agents, claude = repo / "AGENTS.md", repo / "CLAUDE.md"
    block = None
    if agents.is_file():
        block, problems = _block(_read(agents), "AGENTS.md")
        findings += problems
    if block is not None:
        if len(block) > max_lines:
            findings.append(Finding("FAIL", "AGENTS.md", 0,
                                    f"OpenWiki block has {len(block)} lines; the limit is {max_lines}"))
        for line in block:
            stripped = line.strip()
            if stripped.startswith("```"):
                findings.append(Finding("FAIL", "AGENTS.md", 0, "code fence inside the OpenWiki block"))
            elif not stripped.startswith("#") and "openwiki/" not in stripped:
                findings.append(Finding("FAIL", "AGENTS.md", 0,
                                        f"OpenWiki block line is not a pointer: {stripped[:60]}"))
    if claude.is_file() and (START in _read(claude) or END in _read(claude)):
        findings.append(Finding("FAIL", "CLAUDE.md", 0,
                                "contains an OpenWiki block; CLAUDE.md only imports AGENTS.md"))

    if (repo / "openwiki").is_dir():
        if block is None and not findings:
            findings.append(Finding("WARN", "AGENTS.md", 0, "openwiki/ exists but AGENTS.md has no pointer block"))
        ignore = repo / ".openwikiignore"
        baseline = [l for l in _read(framework_root() / "core" / "context" / "openwiki"
                                     / "openwikiignore.baseline").split("\n")
                    if l.strip() and not l.startswith("#")]
        present = set(_read(ignore).split("\n")) if ignore.is_file() else set()
        if not ignore.is_file():
            findings.append(Finding("FAIL", ".openwikiignore", 0, "missing; copy the framework baseline"))
        else:
            for pattern in baseline:
                if pattern not in present:
                    findings.append(Finding("FAIL", ".openwikiignore", 0,
                                            f"baseline pattern '{pattern}' removed"))
    return findings
```

`cli/aidlc/scope.py`:
```python
"""Task scope (guide 3 step 5): the read-only list of paths a task may change, generated
from the approved bundle's MAY CHANGE field at its approval commit. Fails closed."""
from __future__ import annotations

import os
import re
import subprocess
import tempfile
from pathlib import Path

FIELD = re.compile(r"^[A-Z][A-Z ]+?(\s{2,}|\t|$)")


class ScopeError(Exception):
    """No usable scope: the task must not start."""


def parse_may_change(text: str) -> list[str]:
    lines = text.lstrip("﻿").replace("\r\n", "\n").split("\n")
    collected, active, found = [], False, False
    for line in lines:
        if line.startswith("MAY CHANGE"):
            active, found = True, True
            collected.append(line[len("MAY CHANGE"):])
            continue
        if active and FIELD.match(line):
            break
        if active:
            collected.append(line)
    if not found:
        raise ScopeError("no MAY CHANGE field in the bundle")
    joined = re.sub(r"\([^)]*\)", "", " ".join(collected))
    patterns = [p.strip() for p in re.split(r"[,\s]+", joined) if p.strip()]
    if not patterns:
        raise ScopeError("MAY CHANGE field is empty")
    return patterns


def _git(repo: Path, *args: str) -> str:
    result = subprocess.run(["git", *args], cwd=repo, capture_output=True, text=True)
    if result.returncode != 0:
        raise ScopeError(f"git {' '.join(args)}: {result.stderr.strip()}")
    return result.stdout


def bundle_at(repo: Path, ref: str) -> str:
    if ":" not in ref:
        raise ScopeError(f"bundle ref must be <commit>:<path>, got '{ref}'")
    return _git(repo, "show", ref)


def approved_ref(repo: Path, branch: str, approvals_ref: str = "main") -> str:
    text = _git(repo, "show", f"{approvals_ref}:plans/approved-bundles.txt")
    match = None
    for line in text.split("\n"):
        parts = line.split()
        if len(parts) >= 2 and not line.startswith("#") and parts[0] == branch:
            match = parts[1]
    if match is None:
        raise ScopeError(f"no approved bundle for branch '{branch}' in "
                         f"{approvals_ref}:plans/approved-bundles.txt")
    return match


def write_scope(patterns: list[str], out: Path) -> None:
    out.parent.mkdir(parents=True, exist_ok=True)
    fd, tmp = tempfile.mkstemp(dir=out.parent, prefix=".scope-")
    with os.fdopen(fd, "w", encoding="utf-8") as fh:
        fh.write("".join(f"{p}\n" for p in patterns))
    os.chmod(tmp, 0o444)
    os.replace(tmp, out)
```

"""aidlc scope: generate the read-only task scope from an approved bundle."""
from __future__ import annotations

import argparse
from pathlib import Path

from ..cli import command
from ..scope import ScopeError, approved_ref, bundle_at, parse_may_change, write_scope


def _run(args: argparse.Namespace) -> int:
    repo = Path(args.repo).resolve()
    try:
        ref = args.bundle or approved_ref(repo, args.branch, args.approvals_ref)
        patterns = parse_may_change(bundle_at(repo, ref))
        write_scope(patterns, Path(args.out))
    except ScopeError as exc:
        print(f"aidlc scope: {exc}; refusing to start")
        return 1
    print(f"scope: {len(patterns)} pattern(s) from {ref} -> {args.out}")
    return 0
